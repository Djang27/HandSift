# Changelog

All notable changes to HandSift. Versions match the extension's version and the `v*` release tags.

## 0.1.0 (October 22, 2026)

First release. Published on the [Chrome Web Store](https://chromewebstore.google.com/detail/handsift-ai-filter-for-et/giefmpdfjocaghgeneiambmncmlkojjd) on October 23, 2026.

- Labels Etsy listings on search and shop pages: **AI · disclosed** when the seller's own text
  says AI was used, **Likely AI** when several clues add up. Every label explains why.
- Label, blur, or hide flagged listings; Conservative, Balanced, or Aggressive sensitivity.
- First-run welcome page: nothing is sent until you accept the terms and privacy policy.
- Results cached on your device for up to 6 hours and in a shared server cache for up to 3 hours,
  within Etsy's freshness limits.
- The server stops calling Etsy and serves cached results when the daily API quota runs low.
